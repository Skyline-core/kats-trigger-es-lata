# Kat's Trigger — Español (Latinoamérica)

Traducción no oficial al español de Latinoamérica para el juego [Kat's Trigger](https://store.steampowered.com/app/3324650/Kats_Trigger/).

Incluye el archivo de idioma `lang_es.xml` listo para usar en el juego.

## Instalación

1. Copia el archivo `lang_es.xml` en la carpeta de idiomas del juego:

```
steamapps\common\KatsTrigger\ExportFiles\lang
```

En una instalación típica de Steam en Windows, la ruta completa suele ser:

```
C:\Program Files (x86)\Steam\steamapps\common\KatsTrigger\ExportFiles\lang
```

Ahí verás otros archivos como `lang_en.xml`, `lang_JP.xml`, etc. Coloca `lang_es.xml` junto a ellos.

2. Abre el juego. Lo reconoce de forma automática; no hace falta ningún paso extra de instalación.

3. Ve a **Ajustes / Configuración → Idioma** y elige **Español (Latinoamérica)**.
