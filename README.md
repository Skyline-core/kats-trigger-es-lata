# Kat's Trigger — Español (Latinoamérica)

Traducción no oficial al español de Latinoamérica para el juego [Kat's Trigger](https://store.steampowered.com/app/3324650/Kats_Trigger/).

Incluye el archivo de idioma `lang_es.xml` listo para usar en el juego.
